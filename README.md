# 自我覺察課程 — 學習歷程備份

這是「自我覺察」課程學習評核系統的個人學習歷程備份庫，用於保存每個單元（Unit）的任務紀錄、反思內容與 AI 評核結果，避免資料遺失。

## 內容說明

主要檔案為 `高睦郇_自我覺察課程_學習紀錄.json`，結構如下：

- `studentName`：學生姓名
- `stage1Complete`：第一階段（U1–U5）是否完成
- `aiEnabled`：是否啟用 AI 評核
- `aiOverall`：整體 AI 總評與各面向分數（`aiScores`，涵蓋自我覺察、自我管理、社會覺察、人際技巧、負責任的決定）
- `updatedAt`：最後更新時間
- `units`：各單元（目前 1–8）的紀錄，每個單元包含：
  - `task`：任務內容紀錄
  - `reflection`：個人反思
  - `imageBase64`：隨紀錄附上的圖片（base64 編碼）
  - `scores`：自評分數
  - `aiScores`：AI 評核分數
  - `aiFeedback`：AI 回饋內容

## 用途

此儲存庫僅作為個人學習紀錄的版本化備份，每次課程進度更新後提交一次快照，方便追蹤各單元完成狀況與評核內容的變化歷史。
